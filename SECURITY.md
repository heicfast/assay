# Security policy

## Scope

This repository is a measurement-science research framework. It ships
zero operational uplift: behavior text comes only from public benchmarks
fetched at pinned revisions; attack methods are citation-grounded
techniques applied to those behaviors; no working harmful content is
committed or generated by the tooling.

## Novel findings (coordinated disclosure)

If research surfaces a genuinely novel attack vector:

1. Register it: `assay disclosure register --description-file <file>
   --labs <lab>` — the register stores a HASH of the description only.
2. Notify the affected lab (template in `assay/disclosure/__init__.py`)
   within 7 days.
3. Details may be published only when a fix ships OR the 90-day window
   expires. `assay disclosure publish` refuses otherwise (fail-closed).

## Secrets

- API keys live in environment variables only (never committed; the
  environment snapshot records presence booleans, never values).
- `HF_TOKEN` for gated weights: env only.
- Pre-commit scanning: any file matching secret patterns fails review.
  If a secret ever lands in history: rotate immediately — history is not
  a safe place, and "removing" it rewrites nothing that mattered.

## Reporting a vulnerability

Open a private security advisory (GitHub) or contact the maintainers
directly. Please do not open public issues for security problems.
