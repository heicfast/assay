# Code of conduct

## Short version

Be rigorous, be kind, and never fake evidence. The first is enforced by
docs/QUALITY.md; the second by this document.

## Conduct

- We work in a high-stakes field; treat every participant with respect.
  Harassment, personal attacks, or exclusionary behavior are unacceptable.
- Critique work, not people — and expect the same in return.
- Report integrity concerns (fabricated evidence, silent fallbacks,
  citation inventions) to the maintainers; they are treated as the most
  serious class of issue in this project.
- Labelers and contributors are credited; their consent matters.

## Enforcement

Maintainers may remove contributions and contributors that violate this
conduct. Integrity violations (QUALITY.md) result in reversion of the
affected artifacts and a deviation-log entry.
